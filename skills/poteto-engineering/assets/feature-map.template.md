# Feature Map（功能地图）

每个条目描述一条真实用户路径。优先登记高频、关键或经常被含糊指代的功能。用项目验证契约记录通用启动、健康检查和清理命令，在这里链接它。

## <稳定功能 ID> · <用户看到的名称>

- **用户目标与入口**：界面标签、位置、菜单路径或 CLI 子命令。补充同义叫法或易混淆项。
- **适用环境**：平台、角色、开关、测试数据或种子。引用准备和重置入口。
- **操作步骤**：列出实际操作和可复用的 CLI、浏览器或桌面控制入口。
- **预期状态**：写明每个重要转移的可观察结果，覆盖相关失败或边界路径。
- **证据**：列出截图、录屏、trace、日志或断言，以及保存位置。
- **维护**：标注对应代码、最近跑通的版本和已知未覆盖情况。功能改动后重跑相关条目。

示例：`quote-draft-save` 对应“保存草稿”。在测试报价单中修改一项，点击“保存草稿”，离开后重新打开。看到修改值仍然存在才通过。成功提示可截图，持久化需要重开后的断言。
